## Usage

```typescript
import Tariff from 'tariff-js';

// Set your tariff rates (package_name: percentage)
Tariff.set({
  "lodash": 50,    // 50% tariff on lodash
  "axios": 200,    // 200% tariff on axios
  "moment": 150    // 150% tariff on moment
});

// Now when you require these packages, they'll be TARIFFED!
require('lodash'); // This will be 50% slower
require('axios');  // This will be 200% slower
```

### How It Works

When you import a package that has a tariff:
TARIFF measures how long the original import takes.

TARIFF makes the import take longer based on your tariff percentage.

TARIFF announces the tariff with a TREMENDOUS message.
